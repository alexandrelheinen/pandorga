What is left for this file is the studio preview, which renders through `_layouts/text.html` and therefore inherits the generic dossier chrome. The wrapper below is the one hook that stylesheet-side parity needs: it lets assets/css/ledger/projects.css give an editor's preview the same body treatment the published page has — figures, release videos, Plotly frames, Mermaid diagrams and tables on the full column rather than cropped to the 45rem prose measure.
